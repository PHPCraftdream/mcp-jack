Independent review verdicts are used as a bug list, not as a gate.
- Header line order across different names is not pinned in the interop contract (Go net/http and Fetch sort); matrices compare headers as multisets.
- High-level SDK era flows cannot meet the interop contract's pinned bytes (ids, probe version, catalogue, handshake version); all clients drive the low-level signing path with SDK helpers; the gaps are backlog (#128).

- Additive Go client API was allowed for the bridge (stdio consumer option, raw modern request with era detection) and additive durable-state seeding in the internal webhook receiver was accepted for the CLI; the parent noted the second as wider than allowed.
