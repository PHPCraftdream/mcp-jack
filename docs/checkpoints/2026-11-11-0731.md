## Decisions

1. Пользователь явно одобрил через AskUserQuestion замену affected CI/security/deployment compiler pins Go 1.26.10 на **1.26.11** после GO-2026-6859. Это только compiler update: Go language floor 1.25.0 в Go implementation branch, product/dependency versions, locks и Rust MSRV не менялись. Разрешение не распространяется на новые cargo-fuzz dependencies или публикацию.
2. Сохраняются согласованные D2/D3: authenticated durable nonce reservation до authorization/mutation/dispatch, неизвестный исход закрывает работу без automatic retry/replacement/redelivery, startup timestamp floor отклонён. Несколько overlapping announcements допустимы; OLD подписывает до 48 часов после NEXT, без one-pending/cooldown. Fixed P/A не переносятся из-за задержки ACK.
3. Client controller размещён в `client/rotation`, работает с concrete durable store и не меняет static client. `CheckSnapshotClock` атомарно проверяет whole expected trust вместе с fresh guard, закрывая race отдельного snapshot read и clock check. Copied clock tuple не time authority, exact ACK не откатывается при late final failure.
4. Server emission использует отдельный explicit `ResponseKeys` profile, взаимоисключающий fixed signing profiles. Один signer/timestamp/lease, одна проверенная подпись, final gate до первого wire byte, release после write; нет fallback/resign/retry. Hook не считается persistent ring implementation.
5. Server local snapshot отделяет full public chain/state от protected opaque signer references. Reference не даёт key authority, alias handles допустимы, размер ограничен 1024 UTF-8 bytes как local engineering default. Publication contract сохраняет prefixes и old references, добавляет один R и одну revision и проверяет fixed P; contract/codec не считается durable publication. Partial green не означает готовность всей группы к merge.
