# Code of conduct

Be respectful and constructive. Discuss the work, not the person. Harassment, discrimination and personal attacks are not acceptable in issues, pull requests or any other project space.

Maintainers may edit or remove contributions that break these rules and may block repeat offenders. To report a problem, use GitHub's private reporting on the Security tab or contact a maintainer through their GitHub profile.

This is a short statement of intent; it is modeled on the spirit of the Contributor Covenant.
